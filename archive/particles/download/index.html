Download Particles

The last version of Particles, free as it has always been. It is no longer updated.

Particles-1.0.1.jar Version 1.0.1, 2.6 MB, for Spigot and Paper 1.16 to 1.21.11 Download
  • Put the file in your server's plugins folder and restart the server.
  • 1.0.1 fixes the plugin failing to start on server versions it does not support, such as Minecraft 26. It now says the version is not supported and turns itself off.
  • How to set it up is in the wiki.

Running Minecraft 26? Try Particles+

Particles+ is where Particles went on. It has everything Particles had, and:

  • Minecraft 1.16 to 26.3, on Spigot, Paper and Folia
  • A web editor that previews each effect as you build it
  • 3D models from Blockbench, rituals and whole animated scenes
